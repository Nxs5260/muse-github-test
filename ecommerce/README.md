# Mini Shop — 轻量电商演示

零依赖、双击即用的电商演示项目：纯 HTML + CSS + JavaScript，没有构建步骤，没有后端，没有第三方库。

## 怎么跑

直接双击打开 `index.html` 即可。也可以用任何静态服务器托管，例如：

```bash
python3 -m http.server 8000
```

然后访问 http://localhost:8000

## 功能

- 商品列表：12 件示例商品，分 3 个分类
- 分类筛选 + 关键词搜索 + 价格排序
- 商品详情弹窗
- 购物车：加购、增减数量、删除、本地存储（localStorage，刷新不丢）
- 结算：小计、运费（满 $50 免运费，否则 $5.99）、总计，模拟下单并生成订单号
- 响应式布局：手机、平板、桌面都能看

## 目录

```
index.html        页面结构 + 购物车抽屉 + 结算弹窗
css/style.css     全部样式
js/products.js    示例商品数据（改这里就能换自己的商品）
js/app.js         渲染、筛选、购物车、结算逻辑
```

## 换成自己的商品

改 `js/products.js` 里的数组就行，每件商品字段：

- `id`：唯一编号
- `name`：商品名
- `price`：价格（美元）
- `category`：`digital`（数码配件）/ `outdoor`（户外运动）/ `home`（居家清洁）
- `rating`：评分
- `emoji`：卡片上的示意图标
- `desc`：一句话描述

## 注意

这是一个前端演示：没有真实支付、没有真实库存和物流，下单只是模拟流程，不会产生真实订单和扣款。
